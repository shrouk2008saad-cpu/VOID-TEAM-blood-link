# Blood Link | بوابة إنقاذ الحياة (الإصدار المطور v5)

منصة تفاعلية ثلاثية الأبعاد للتبرع بالدم وربط المتبرعين بالمرضى والمستشفيات في جميع محافظات مصر الـ 27.

## التحديثات الجديدة في v5
1. **خيار "لا أعلم فصيلتي" للمتبرعين الجدد:** عند اختياره يظهر تنبيه إرشادي للمتبرع بضرورة معرفة فصيلة دمه وتسجيلها أثناء التبرع لتسهيل تحديدها في مرات التبرع القادمة.
2. **تحديد الموقع الحالي وأقرب مركز تبرع:** حقل لتسجيل موقع المتبرع الحالي (مع زر تحديد GPS تلقائي)، وبمجرد التسجيل يظهر أقرب بنك دم أو مستشفى في محافظته مع رابط مباشر لخرائط جوجل.
3. **قسم التبرع المالي لتوفير أكياس الدم:** مخصص لمن تمنعهم ظروفهم الصحية من التبرع بالدم، يتيح المساهمة بمبلغ مالي لتغطية تكلفة أكياس الدم وفحوصات التوافق وإصدار إيصال مساهمة فوري.
4. **خلفية وريد ثلاثية الأبعاد ممتدة لكامل الموقع:** أنيميشن تفاعلي لوريد نابض تتدفق بداخله كرات الدم الحمراء وجزيئات البلازما ويتفاعل مع حركة المؤشر والتمرير في كافة أقسام الموقع.
